# 2.0.1 开销验证

2026-10-08，M4 Pro / macOS 27.0.1，本机临时签名构建。

## 改动

- 任务状态通过原生 libproc/getpriority 读取，取消每次读取启动 `priority-helper --inspect` 子进程。
- 会话监督使用 kqueue 的进程退出/会话文件变化事件和单次到期超时。正常等待期间没有每秒轮询；接口失败时仍使用原兼容恢复路径。
- 无活动任务时不排队读取会话；状态不变时不再次重建菜单。

## 测量

- 2.0.1 刚启动、菜单关闭、无活动会话：CPU 显示 0.0%；15 秒内累计 CPU 时间保持 0:00.09。
- 同一状态下，footprint 的 phys_footprint 为 9361 KB，约 9.1 MiB，峰值 9857 KB。RSS 为 50768 KB，包含共享/映射页面，不能作为软件独占内存。
- 优化前已有运行历史的实例 phys_footprint 约 28 MB；菜单、授权框和缓存会影响该指标。两个实例的历史状态不同，不将 28→9 MB 当成严格可复现的优化降幅。
- 100 次相同进程身份读取：直接调用共约 0.086 ms；原子进程方式共约 6737 ms。该微基准包含 Process 启动及等待成本，只说明状态读取路径减少开销，不代表整款软件或用户任务的加速倍数。

## 功能保障

普通身份与输入检查通过。管理员集成检查的到期恢复、提前取消、应用退出恢复、外部修改保留和非法请求拒绝全部通过；通过一次 sample 采样确认监督进程等待在 kevent，而不是周期性 nanosleep。

这些结果不是长时间、多会话、睡眠唤醒或所有应用的性能证明。AppKit 内存会随实际操作和系统缓存状态变化；不承诺固定 CPU 百分比或固定内存上限。
