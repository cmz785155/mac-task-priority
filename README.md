# Mac 能耗模式 · Mac Power Modes

轻量的 Apple Silicon Mac 菜单栏工具，用四个场景配置 macOS 原生电源策略。原生 Swift / AppKit，无第三方运行时、网络请求和持续 CPU/GPU 采样。

## 四种模式

| 场景 | macOS 策略 | 适用任务 |
| --- | --- | --- |
| 插电 · 极致性能 | 高电量模式（High Power） | 持续计算、视频编辑、渲染 |
| 插电 · 普通均衡 | 自动（Automatic） | 日常工作 |
| 离电 · 高性能 | 高电量模式（High Power） | 离电重负载，电池消耗更高 |
| 离电 · 轻度工作 | 低电量模式（Low Power） | 码字、浏览、聊天、影音 |

插电和电池策略独立保存，macOS 在插拔电源时自动切换，不需要本软件常驻。勾选表示各电源配置；顶部表示当前供电来源。退出软件后已配置的策略继续生效。

软件不会关闭或暂停应用、项目，不修改风扇、睡眠、屏幕亮度或系统温控。启动时不改变现有电源设置。

## 安装和使用

从仓库 Releases 下载 Apple Silicon 安装包，解压后将 `Mac能耗模式.app` 放入“应用程序”，双击运行并点击菜单栏闪电图标。仅允许一个应用实例。

当前发布采用临时签名，没有 Developer ID 签名或 Apple 公证；首次启动可能被 macOS 拦截。也可以按照下方说明从源码构建。

切换后读取系统设置验证结果。点击已经生效的策略不会再次执行提权操作。打开菜单、切换电源或睡眠唤醒时异步刷新状态；不使用轮询计时器。适配器功率来自 IOKit 的系统报告，表示供电能力，不能当作实时整机耗电。

## 管理员授权

默认每次实际修改通过 macOS 管理员授权对话框执行。软件不读取或保存密码。

可选菜单“启用首次授权免密切换…”：授权一次后，为当前账户添加受限 sudoers 规则。安装路径为 `/private/etc/sudoers.d/local-macpowermodes-<UID>`，root:wheel 所有，权限 0440。使用 visudo 校验，原子安装；不修改主 sudoers 文件、不安装常驻 root 服务、不提权用户可修改的程序。

仅允许系统 `/usr/bin/pmset` 的以下五组完整参数，无通配符，禁止 SETENV：

```text
-c powermode 2
-c powermode 0
-b powermode 2
-b powermode 1
-a powermode 0
```

此权限属于当前账户，该账户下的其他程序也可执行同样五项操作。风扇操作、额外 pmset 参数和任意命令均不包含在规则中。免密切换使用 `sudo -n`，不会等待终端密码。

菜单“撤销免密切换…”经系统管理员授权后删除对应规则，不改变现有电源策略。卸载应用前请先撤销；单纯删除应用不会移除规则。菜单“两种电源均恢复自动模式…”会将两种电源均设为自动，并非恢复使用本软件前的任意自定义策略。

## 兼容性与性能边界

构建目标为 Apple Silicon、macOS 15.1 及以上；实际验证环境为 M4 Pro MacBook Pro、macOS 27.0.1。其他系统版本尚未实机验证，尤其 `pmset powermode` 的写入兼容性。读取不到模式时显示“未知”；系统未报告高电量能力时禁用高性能选项。

支持 High Power 的机型以 [Apple 官方说明](https://support.apple.com/101613) 为准。高电量模式允许更积极的散热，性能收益取决于负载；不会锁定频率或保证满功耗。离电高性能无法承诺电池零损耗。CPU/GPU 利用率或功耗升高不能直接证明应用更快；任务也可能受内存带宽等条件限制。

对比性能时，保持相同电源、任务、显示亮度和环境，分别用自动与高电量模式运行，比较实际完成时间或吞吐量。软件报告的芯片功率与插座端功率不能直接混比。14 英寸 M4 Pro 在充电同时使用高电量模式时，Apple 建议 96W 电源适配器。

## 构建与检查

需要 macOS 和 Xcode Command Line Tools：

```sh
./scripts/build.sh
./scripts/test.sh
```

输出：`dist/release/Mac能耗模式.app`。可给构建脚本传入自定义绝对输出路径。

检查包括电源来源解析、异常/缺失数据、已生效策略判断，以及拒绝非白名单操作；不会更改电源设置或安装权限规则。可对构建产物运行 `--self-test` 进行只读系统回读验证。

GitHub Actions 自动编译、运行检查、验证临时签名并生成 ZIP。CI 编译成功不代表所有 Mac 机型均已通过实机切换验证。
